                        Period Navigator
                             |

                      |             |

                   [<] Button    [>] Button
                   Go Back       Go Forward
                      |             |

            navigatePeriod(-1)  navigatePeriod(1)
                      |             |
                      +------+------+
                             |
                             v
                  if (type === 'month') {
                    offset: 0 → -1 (previous month)
                    offset: -1 → 0 (current month)
                    limit: -24 to 0
                  }
                  
                  if (type === 'year') {
                    offset: 0 → -1 (previous year)
                    offset: -1 → 0 (current year)
                    limit: -5 to 0
                  }

        Period Display Examples:
        
        MONTHLY VIEW:
        offset=0:  "Este mes" (November 2025)
        offset=-1: "Octubre 2025"
        offset=-2: "Septiembre 2025"
        
        YEARLY VIEW:
        offset=0:  "Este año" (2025)
        offset=-1: "2024"
        offset=-2: "2023"
